# MkMudae Discord Bot

## 🚀 Invite the MkMudae to your server!

You can invite the bot to your Discord server using **[this link](https://discord.com/oauth2/authorize?client_id=1431375151601029261&permissions=397284863056&integration_type=0&scope=bot+applications.commands)**

---

## 📖 How to Use

Once the bot is added to your server, you can explore all its features using the built-in slash commands:

- **`/help`** — Displays a list of available commands and general help.
- **`/summary`** — Shows a summary of the bot’s main functionalities and options.

Use these commands to learn about every feature the bot offers and how to interact with it.

---

## 🛠️ Features

### 📚 Bot Help
- **`/help`** — View the full bot help.
- Autocomplete support for slash commands (`/`), making them easier and faster to use.

---

### 🎮 Basic Game
- **`$roll` (`$r`)** — Get a random player
- **`$buy`** — Buy a player from another user
- **`$sell` (`$sl`)** — Sell a player
- **`$trade` (`$td`)** — Trade players with another user
- **`$gift` (`$g`)** — Gift a player to another user
- **`$buyelo` (`$be`)** — Buy Elo using coins

---

### 📊 Information
- **`$roster` (`$rt`)** — View your player collection
- **`$playerinfo` (`$pi`)** — View detailed information about a player
- **`$playerstats` (`$ps`)** — View detailed player statistics
- **`$rosterstats` (`$rs`)** — View your roster sorted by average stats
- **`$userinfo` (`$ui`)** — View user information
- **`$timerinfo` (`$ti`)** — View timers and reset information
- **`$trackinfo` (`$tri`)** — View available tracks
- **`$rankinfo` (`$ri`)** — View rank information
- **`$loungeodds` (`$lo`)** — View player distribution by Lounge rank
- **`$leaderboardmmr` (`$lbm`)** — Top users by average lineup MMR
- **`$leaderboard` (`$lb`)** — Top users by Elo

---

### ⭐ Wishlist
- **`$wishlist` (`$wl`)** — View your wishlist
- **`$wishlistadd` (`$wla`)** — Add a player to your wishlist
- **`$wishlistremove` (`$wlr`)** — Remove a player from your wishlist

---

### 👥 Lineup
- **`$lineup` (`$lu`)** — Set your full lineup
- **`$lineupadd` (`$lua`)** — Add players to your lineup
- **`$lineupremove` (`$lur`)** — Remove players from your lineup

---

### 🏷️ Team Customization
- **`$teamname` (`$tn`)** — Change your team name
- **`$editteamname` (`$etn`)** — Change another user’s team name (admin role required)
- **`$tag`** — Change your team tag
- **`$edittag` (`$etag`)** — Change another user’s tag (admin role required)
- **`$alias` (`$a`)** — Create a custom alias for a player
- **`$removealias` (`$ra`)** — Remove a player alias

---

### 🏁 Tracks
- **`$trackpick` (`$trp`)** — Assign a track to a preferred type
- **`$trackremove` (`$trr`)** — Remove one or all tracks from a type

---

### 🏋️ Training
- **`$train` (`$t`)** — Train a player to improve their attributes

---

### ⚔️ Wars and Scrims
- **`$war` (`$w`)** — Challenge a user to a war
- **`$scrim` (`$s`)** — Challenge a user to a scrim
- **`$tournamentwar` (`$tw`)** — Challenge a user to a tournament war
- **`$cpuwar` (`$cw`)** — Challenge a CPU team
- **`$accept`** — Accept a pending war or scrim
- **`$deny`** — Reject a pending war or scrim
- **`$stop`** — Stop an active war
- **`$calc`** — Calculate Elo changes or view average stats

---

### 🔧 Administration
- **`$ban` / `$unban`** — Ban or unban users (admin role required)
- **`$coinsadd` (`$ca`)** — Add coins to a user (admin role required)
- **`$coinsremove` (`$cr`)** — Remove coins from a user (admin role required)
- **`$removeplayer` (`$rp`)** — Remove a player from a user's roster (admin role required)
- **`$removealiasuser` (`$rau`)** — Remove a player alias (admin role required)
- **`$fullreset`** — Full server reset (server owner only)
- **`$thanos`** — Execute the Thanos snap (server owner only)
- **`$adminrole`** — Configure the bot admin role (server owner only)

---

### 🌍 Languages
- The bot supports **English, Spanish, and French**.
- You can override the server language using:
    - /help language:[language] command:[command]
    - /summary language:[language] option:[option]
